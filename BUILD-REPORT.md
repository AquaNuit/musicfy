## Lossless feature (headline)

- Lossless shelf streams full-length FLAC from the Internet Archive
  (advancedsearch `mediatype:audio AND format:FLAC`, per-item metadata lookup to find
  the FLAC file, streamed from `archive.org/download/...`).
- File picker plays the user's own FLAC/WAV/ALAC via `URL.createObjectURL`, with real
  format label and an estimated bitrate (`size × 8 / duration`) in the player.
- Quality selector (Data saver / Normal / Lossless / Hi-Res Lossless) persisted in
  `localStorage`, shown as a header chip; `LOSSLESS` badge on lossless tracks.
- UI + README note Safari may not decode FLAC in-browser (native-decoder dependency).

## Limitations / honest notes

- Catalog playback is **30-second iTunes previews** only (labelled in UI) — no
  full-length commercial catalog is available from any free keyless API.
- The Lossless shelf makes one metadata request per candidate item (capped at 10
  tracks), so it can take a few seconds to populate; it degrades gracefully offline.
- The APK workflow produces an **unsigned debug APK** (fine for direct installs, not
  Play Store). It was written to standard Capacitor/Gradle conventions but has **not
  been run** — the first Actions run is the real test; `android/` is generated by
  `cap add android` in CI, not committed.
- PWA install requires serving over HTTPS (GitHub Pages qualifies) or localhost.
- Lyrics depend on LRCLIB coverage; tracks without synced lyrics fall back to plain
  lyrics or a "not found" message.
