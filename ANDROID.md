# Building the Android APK

Musicfy is a plain static web app. [Capacitor](https://capacitorjs.com) wraps it in a
native Android shell — no changes to the web code are needed.

## Option A — GitHub Actions (no local setup)

1. Push this repo to GitHub.
2. Either create a **Release**, or open **Actions → Build Android APK → Run workflow**.
3. Download `musicfy-debug-apk` from the workflow run (on a release, the APK is also
   attached to the release page as `app-debug.apk`).
4. Install the APK on your phone (you may need to allow "install from unknown sources"
   for your browser/files app).

## Option B — Build locally

You need Node.js 18+, JDK 17, and Android Studio (with an Android SDK installed).

```bash
npm install          # installs Capacitor
npx cap add android  # creates the android/ project (first time only)
npx cap sync         # copies the web app into the Android project
npx cap open android # opens Android Studio
```

In Android Studio: **Build → Build App Bundle(s) / APK(s) → Build APK(s)**.
The debug APK lands in `android/app/build/outputs/apk/debug/app-debug.apk`.

After changing any web file (`index.html`, `app.js`, `styles.css`), run
`npx cap sync` again before rebuilding.

## Notes

- `appId` is `com.musicfy.app`, `appName` is `Musicfy` (see `capacitor.config.ts`).
- The `android/` folder is generated by Capacitor and is git-ignored; the Actions
  workflow recreates it on every run.
- The debug APK is fine for personal installs and sharing. For a Play Store release
  you would need a signed release build (keystore + `assembleRelease`) — out of scope here.
- FLAC playback inside the app uses the WebView's native decoder; on Android
  (Chrome-based WebView) FLAC is supported.
